`proc://`: jobs/services; `proc://<id>` status/output; `proc://<id>/kill` cancels/stops jobs/agents/services, omit `content`. Named services only: write sends stdin (empty = Enter); `proc://<id>/mode`: `persist`|`session`|`detached` (`persist`/`session` change lifetime without restarting; first switching to `detached` RESTARTS the command without a PTY, forces persistence beyond the broker, and prevents switching back to `session`). `proc://<id>/streams` lists a bash job's pipes, `proc://<id>/streams/<n>` reads what crossed pipe `n` so far (live under `| tail`/`| grep`; never rerun to see it).

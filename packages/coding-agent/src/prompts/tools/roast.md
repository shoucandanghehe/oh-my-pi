Vent about whatever rubs you the wrong way while working, like a quick complaint to a coworker.

Write non-empty plain text to `xd://roast`; no JSON or fixed template. A subjective reaction is enough; no proof of a bug, impact analysis, or proposed solution needed.

Reports stay in the local `roasts` table in `~/.omp/roast.db` (XDG data directory when configured), with time, session ID, working directory, model, and version. No upload, no auto-QA consent dialog, no automatic transcript or prompt attachment. Read the SQLite file to review saved feedback.

Say your piece, then get back to work. No need to go looking for things to complain about.

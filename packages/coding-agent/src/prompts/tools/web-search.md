Query: site: or -site:, after: or before: YYYY-MM-DD, inurl:, intitle:, filetype:, "phrase", -term, OR.{{#if xSearch}} X posts/reactions → `site:x.com`, `site:x.com/<handle>`, or `from:<handle>`; `-from:<handle>` excludes.{{/if}} Prefer primary sources; MUST link citations.

Query filters are best-effort: a dimension matching no remaining sources is relaxed with a Note. Post-filtering affects Sources only, not generated answers or Citations; verify cited URLs against required constraints.

`limit`/`num_search_results` control provider-dependent search breadth or parsed source/citation counts, not entries in generated answer text; `num_search_results` usually takes precedence. `max_tokens` is honored only by supporting providers, not a hard cap on final tool output.
